## เครื่องคิดเลขวิทยาศาสตร์ "อัศวิน" (`calculator/`)
เว็บ: https://nytoff5389-boop.github.io/space-schedule/calculator/ — เป็นเว็บแยกจากตารางเรียน แค่อยู่ใน repo เดียวกัน
- หน้าตาแบบเครื่องคิดเลขวิทยาศาสตร์สีชมพู ปุ่ม SHIFT / ลูกศร + OK / FORMAT / EXE, แสดงเศษส่วน รูท π แบบตำรา
- แอปในเครื่อง: คำนวณ, สถิติ (1 ตัวแปร, y=a+bx), การแจกแจง (ปกติ/ทวินาม/ปัวซง), ตารางค่า f(x), สมการ (ระบบ 2–4 ตัวแปร, พหุนามดีกรี 2–4), อสมการ, จำนวนเชิงซ้อน, ฐานเลข, อัตราส่วน
- ฟังก์ชัน: ∫ d/dx Σ Π, SOLVE, nPr nCr, ไฮเพอร์โบลิก, ค่าคงที่วิทยาศาสตร์, ตัวแปร A–F x y z M
- เพิ่มลงหน้าจอโฮมของ iPhone/iPad ได้ (Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม) ใช้ออฟไลน์ได้
- โค้ด: `calculator/engine.js` (ตัวคำนวณ) · `calculator/app.js` (หน้าจอ/ปุ่ม) · `calculator/calc.css`

## แจ้งเตือน (ntfy)
GitHub Actions (`.github/workflows/notify.yml`) รันทุกเช้า 04:00 น. แล้วตั้งเวลาส่งแจ้งเตือนของวันนั้นไปที่ ntfy
(สรุปเช้า 06:30, ก่อนเรียน 15 นาที, 19:00 แจ้งวันหยุด/วันว่าง/Lab/สอบล่วงหน้า)

บน iPhone: ติดตั้งแอป ntfy → กด + → ใส่ topic ที่อยู่ใน `data/schedule.json` (`ntfy.topic`)

## แก้ไขข้อมูล
ทุกอย่างอยู่ใน `data/schedule.json`
- `weekly` คาบเรียนประจำสัปดาห์ • `topics` หัวข้อรายวัน • `exams` • `holidays` • `events`
- `ntfy` ตั้งค่าเวลาแจ้งเตือน (`leadMinutes`, `labRemindDays`, ...)
- ห้อง Lab กำหนดใน `labRooms`

ดูตัวอย่างแจ้งเตือนของวันใดก็ได้: `DATE=2026-11-12 DRY=1 node notify/send.mjs`
