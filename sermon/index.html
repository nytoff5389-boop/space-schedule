สร้างบทเรียนพระคัมภีร์ทีละขั้น จากพระคริสตธรรมคัมภีร์ ฉบับมาตรฐาน (THSV11)

    ตั้งค่าระบบช่วยคิด

    ใส่รหัส Claude API ของคุณ

    ระบบช่วยคิดคำนำ บริบท บทเรียน บทสรุป และคำถาม ต้องใช้รหัส API ของ Anthropic รหัสนี้เก็บไว้ในเครื่องนี้เท่านั้น ไม่ถูกส่งไปที่อื่นนอกจาก Anthropic

    1. สมัครและเติมเงินที่ console.anthropic.com
    2. กด Create Key แล้วคัดลอกรหัสที่ขึ้นต้นด้วย sk-ant-
    3. วางในช่องด้านล่างแล้วกดบันทึก
